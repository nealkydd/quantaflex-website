Our local-first bias.

We are biased towards the computer in front of you. It already holds the source material, it has the processing power, and it is where the decisions are being made. For a great deal of media work, sending every file away before you can begin is an unnecessary detour.

The hidden cost of a cloud-first workflow is not only the monthly charge. It is the upload bar, the browser tab, the question of which version is final, and the repeated movement of large files between services. That can be perfectly acceptable when a remote team needs to work together. It is less helpful when one person simply wants to prepare, inspect, encode or play the file already on their own machine.

Use the cloud where it earns its place.

Cloud tools are valuable for live collaboration, shared access, remote backup and publishing. Quantaflex uses an internet connection when the job calls for it: live calls, activation and connected publishing. The difference is that the core media workflow does not have to be surrendered to the cloud in order to work.

The honest part.

Local-first also means taking care of your own files. You need sensible storage and a proper backup routine. Larger video projects still depend on the capability of your own computer. We think that is a fair trade: you know where the work is, you choose how it is managed, and you are not locked out of the essentials because a monthly plan ends.
