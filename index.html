What is Quantaflex?

Quantaflex is professional media software for creators, educators, trainers and media professionals. The modular desktop platform brings social video editing, online teaching and presentations, private video communication, advanced media encoding, home theatre playback and technical media analysis into one consistent application for macOS and Windows. Quantaflex is built around local-first workflows, user control and exact-lossless processing where it matters.
